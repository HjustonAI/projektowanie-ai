# projektowanie-ai

Sposób współprojektowania inteligentnych systemów z AI — agentów, skilli, pluginów
i procesów, w których LLM wykonuje część pracy: funkcjonalność i prostota, projektowanie
pracy myślowej, context as code, dobór środków do zadania, rozwój z doświadczenia.

## Pliki

- [SKILL.md](SKILL.md) — skill Claude Code; uruchamiany tylko ręcznie:
  `/projektowanie-ai <co chcesz stworzyć lub ocenić>`
- [KONTEKST.md](KONTEKST.md) — ta sama treść jako samodzielny kontekst do dowolnej rozmowy z LLM
- [ROZWINIECIE.md](ROZWINIECIE.md) — uzasadnienia, dylematy i przykłady

## Instalacja w Claude Code

```sh
git clone https://github.com/HjustonAI/projektowanie-ai.git ~/.claude/skills/projektowanie-ai
```

## Bez instalacji

Dołącz KONTEKST.md (w razie potrzeby także ROZWINIECIE.md) do rozmowy z dowolnym modelem
i użyj polecenia z sekcji „Jak użyć tego kontekstu”.
